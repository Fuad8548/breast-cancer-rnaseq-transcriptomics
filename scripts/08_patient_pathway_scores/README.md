Previously we had:
> GSEA: “This biological program is enriched toward T3.”

Now we ask:
> ssGSEA: “Does this program's activity actually shift within individual patients from T1 to T3?”

GSVA/ssGSEA is specifically designed to transform a gene-by-sample expression matrix into gene-set-by-sample scores, enabling pathway-level analysis across individual samples.

One caution: these four signatures were chosen from the same cohort's GSEA findings, so this is **exploratory confirmation/internal consistency**, not independent validation.
